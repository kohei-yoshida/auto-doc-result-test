# Calculator

The calculator accepts two numeric inputs and performs one selected arithmetic operation.

## Supported operations

| Operation | Result |
| --- | --- |
| Add | First number plus second number |
| Subtract | Second number subtracted from first number |
| Multiply | First number multiplied by second number |
| Divide | First number divided by second number |

Division by zero is rejected with an error rather than returning an infinite value. Empty or invalid input is also rejected.

## Keyboard support

Pressing the Enter key while focused on either number input will perform addition of the two input values, reusing the existing success and error display behavior.
