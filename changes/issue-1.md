# Add Enter-key support for calculator addition

## Related work

- Source issue: https://github.com/kohei-yoshida/auto-doc-source-test/issues/1
- Implementation PR: https://github.com/kohei-yoshida/auto-doc-source-test/pull/2

## User-visible change

Users can now press Enter while focused on either numeric input field to trigger addition and see the result or error without clicking the Add button.
